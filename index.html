About

The long version

I'm in my third year of a B.Tech in Computer Science at VIT Bhopal University, currently at a CGPA of 8.59. The core curriculum gave me the parts that don't go out of date — data structures, algorithms, databases, object-oriented design — and most of my own time since has gone into learning how to turn those into systems that produce a result someone else can reproduce.

Python is where I'm strongest, and most of my recent work sits around large language models: prompt engineering, retrieval-augmented generation, and the unglamorous discipline of constraining model output to a schema so downstream code can rely on it. A model that returns free text is a demo. One that returns validated JSON is a component.

The other half is data. I'm comfortable owning a pipeline end to end — raw ingestion, cleaning, missing-value handling, encoding, feature engineering — through to a benchmarked result on a held-out set that a teammate can rerun and get the same numbers from. That habit came out of a hackathon deadline and stuck.

Underneath all of it I keep a steady DSA practice. It's partly interview preparation and partly because a clean solution to a hard problem remains one of the more satisfying things in this field.

What I want next is a software engineering or Generative AI internship on a team that ships — somewhere I can learn from code review, own something small end to end, and find out how these ideas hold up at real scale.

Research

Soybean Leaf Disease Classification

Benchmarked four lightweight CNNs — MobileNetV2, MobileNetV3-Small, EfficientNet-B0, DenseNet121 — on an 8-class, 1,600-image ASDID subset through one modular train, evaluate, and quantize pipeline running on Colab and Kaggle GPUs. Two-stage fine-tuning lifted MobileNetV2 from 81.7% to 92.9% test accuracy, then INT8 quantization cut it from 9.3 MB to 2.6 MB for Raspberry Pi deployment at under a percentage point of accuracy lost.

92.9% accuracy · 0.93 macro-F1 · 3.6× smaller

Resume Analyzer

An LLM-powered screening tool that parses resumes into structured fields and scores them against a target job description on skill coverage and structure. The decision that made it usable: constraining model output to a strict JSON schema, so scores, missing skills, and formatting flags render deterministically instead of as free text a parser has to guess at.
